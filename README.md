## 🎯 Assignment

Create a new React project and implement a **movie filtering system** that allows users to filter a list of films by genre.

The movie array is already provided:

```jsx
[
  { title: "Inception", genre: "Fantascienza" },
  { title: "Il Padrino", genre: "Thriller" },
  { title: "Titanic", genre: "Romantico" },
  { title: "Batman", genre: "Azione" },
  { title: "Interstellar", genre: "Fantascienza" },
  { title: "Pulp Fiction", genre: "Thriller" },
];
```

Use React state and the `useEffect` hook to manage the dynamic filtering process.

**For this exercise, prioritize the application logic and state management.** Once everything works correctly, you can focus on styling the interface.

### Requirements

- The filter must update dynamically whenever the user selects a genre from the `select` element.
- If no genre is selected, all movies must be displayed.
